# student-assistant
## Опис
Student Assistant — застосунок для оптимізації навчального процесу з функціоналом створення, моніторингу та контролю реалізації завдань.
## Архітектура
Кросплатформна, гетерогенна система з кількох незалежних клієнтів (веб,
десктоп, нативний C++, аналітика на Python), що обмінюються даними через
спільний файл tasks.json.
## Технології
- React - веб-інтерфейс (Модуль 2)
- Electron / NW.js - десктопна обгортка (Модуль 3)
- C++ / Qt - нативний десктопний клієнт (Модуль 4)
- Python / Flet - аналітична панель (Модуль 4)
## Структура репозиторію
- frontend/ - React-фронтенд
- desktop-container/ - Electron/NW.js-контейнер
- cpp-core/ - нативний C++/Qt-клієнт
- python-analytics/ - аналітичний модуль на Python
- data/ - спільний файл обміну даними tasks.json
